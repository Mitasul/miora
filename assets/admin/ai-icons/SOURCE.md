# AI 品牌图标来源

下载日期：2026-10-16。

图标来源为 LobeHub 的 lobe-icons 项目，静态 SVG 包版本为 @lobehub/icons-static-svg@1.95.1。本目录的 114 个 SVG 均保留下载的原始文件，不重绘品牌标识。

覆盖通用模型、国内厂商、第三方推理平台、嵌入与重排模型，以及绘图、视频、语音和音乐模型。新增资源沿用同一版本和许可证，不打包无关的编辑器、社交或工作流工具图标。

上游 MIT 许可证原文保留在同目录 LICENSE，并内嵌于管理控制台的 ai-icons/LICENSE 静态路由。

运行时只读取 Rust 内嵌的同源资源，不使用外网图标服务，不引入 npm 运行时依赖。

品牌图标只用于识别供应商和模型家族，不替换 Miora 的项目标识。各品牌名称与标识属于各自权利人。未知供应商与模型保留通用图标。
